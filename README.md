# Play PokeFields on Linux (UNOFFICIALLY)

Whilst we are waiting for Official Linux support, here is some guides and scripts to get you playing when you are running Linux.

**NOTE: THIS IS AN UNOFFICIAL REPO THAT HAS NOTHING TO DO WITH ANYONE AT POKEFIELDS.**

I will try and get this working on as many distros as possible, you can also feel free to add in a PR with instructions for a distro you are using.

## CachyOS

### Part One: Prerequisites

First, you will need to install the cachyos-gaming-meta package.  (If you selected gaming packages whilst installing CachyOS, you already have this!)

Load up a Terminal and run:

`sudo pacman -S cachyos-gaming-meta cachyos-gaming-applications`

If you don't trust yourself (or me telling you) to enter stuff into the Terminal, then you can do so in the GUI.

Load CachyOS Hello, then click on "Apps/Tweaks". Finally click on the "Install Gaming Packages" button to install all the prerequisites you need.

If you would like to see more about this, you can visit the CachyOS wiki: [CachysOS Wiki | Gaming](https://wiki.cachyos.org/configuration/gaming/)
